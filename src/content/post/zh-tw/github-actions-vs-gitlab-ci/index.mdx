## 前言

用同一條 pipeline 在兩套工具上各實作一次，整理各自在速度、可讀性與價格上的勝出項目。

## 現場筆記

在處理 CI-CD 問題的過程中，反覆看到的幾個模式：

- 簡單的版本撐過了每次重構，聰明的版本沒有。
- 邊做邊寫的文件，比事後補寫的耐用得多。
- 同一個問題第二次出現時，它就已經是模式了——幫它命名吧。
