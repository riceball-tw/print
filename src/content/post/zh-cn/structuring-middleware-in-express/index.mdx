## 前言

讨论放在 router 层还是 app 层、错误中间件该放哪，以及如何避免 200 行的 index.js。

## 核心心智模型

- 从最小可运行的版本开始，并让它可观测。
- 把你正在承担的取舍写下来，而不只是写下交付了什么功能。
- 团队规模变化时重新审视决策；Express.js 里的多数选择都有保质期。

## 动手起点

1. 在实验分支重现问题，放在你信得过的度量指标旁边。
2. 一次只改变一个变量，让 diff 小到能用一句话解释清楚。
3. 保留成果，丢掉脚手架。

```bash
git switch -c experiment/one-thing
```
